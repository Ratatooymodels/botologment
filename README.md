# Бот «Карточка товара для маркетплейса»

Продавец присылает фото товара, бот возвращает:
1. **готовую карточку** 3:4 (студийная сцена + название + 3–4 преимущества);
2. **чистую сцену** без текста (вторая фотка в галерею);
3. **PNG-вырезку** товара на прозрачном фоне.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Python 3.10–3.12
pip install -r requirements.txt
cp .env.example .env     # впишите TELEGRAM_BOT_TOKEN (и ANTHROPIC_API_KEY)
python bot.py
```

При первом запуске `rembg` скачает веса модели (~170 МБ).

## Как это работает

| Шаг | Чем делается |
|---|---|
| Вырезка фона | `rembg` (ISNet), локально, бесплатно |
| Сцена | градиент + свет + контактная тень + отражение (Pillow) или AI-сцена через fal.ai FLUX |
| Тексты | Claude смотрит на фото + подпись продавца, возвращает JSON (название, подзаголовок, 3–4 пункта) |
| Инфографика | Pillow: заголовок, плашки с иконками, тема (светлая/тёмная) выбирается по яркости фона |

Файлы: `pipeline.py` (вся обработка, можно использовать отдельно), `bot.py` (Telegram и лимиты).

## Важно знать

- **Шрифт.** Нужен TTF с кириллицей. Из коробки берётся DejaVu/Liberation/Arial; для красоты положите
  `Inter-Bold.ttf` и `Inter-Regular.ttf` в папку `fonts/`.
- **Правдивость текстов.** Claude получает запрет выдумывать характеристики, но сверяйте результат:
  ответственность за карточку на продавце. Правила площадок к инфографике и размерам проверьте
  в актуальных требованиях WB/Ozon.
- **AI-сцена** экспериментальная: модель рисует пустую поверхность, и товар не всегда «садится» на неё идеально.
  Для стабильного результата используйте градиентные стили.
- **Сложные товары** (прозрачное стекло, чёрное на чёрном, мех) вырезаются хуже. Совет: фото на контрастном фоне.
- **Нагрузка.** `rembg` на CPU обрабатывает фото за 3–10 секунд. Для потока клиентов вынесите вырезку
  на GPU (или в fal.ai/Replicate) и добавьте очередь.

## Куда развивать

- Оплата: Telegram Stars (`send_invoice` с валютой `XTR`) или ЮKassa вместо дневного лимита.
- Свой текст: кнопка «Изменить преимущества», когда пользователь присылает правки в чат.
- Размеры под площадки (WB, Ozon, Яндекс Маркет) и пакетная обработка альбома.
- Хранилище и webhook вместо polling для продакшена, Docker и systemd.

## Запуск на сервере (24/7)

```bash
# на чистом Ubuntu VPS (от 2 ГБ RAM, лучше 4 ГБ)
curl -fsSL https://get.docker.com | sh
# скопируйте папку проекта на сервер (scp/git), создайте .env из .env.example
docker compose up -d --build     # запуск
docker compose logs -f           # логи
docker compose up -d --build     # обновление после правок кода
```

## Полностью бесплатный режим

Ни за что не платите: вырезка фона локальной компактной моделью (`silueta`), тексты через Gemini,
хостинг на бесплатном тарифе Render, бот работает по webhook.

1. Ключ Gemini: aistudio.google.com → Get API key (без карты).
2. Код на GitHub (файл `.env` не коммитьте).
3. render.com → New → Blueprint → репозиторий, `render.yaml` подхватится сам.
4. Впишите `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY`.
5. Бесплатный пинг (UptimeRobot) на адрес сервиса раз в 10 минут, чтобы не было «просыпания».

Ограничения:
- Бесплатный Render даёт 512 МБ RAM. Модель `silueta` рассчитана на такой объём, но вплотную: если сервис
  падает по памяти, уменьшите `CARD_WIDTH`, либо запускайте бота дома (на старом ноутбуке) с `REMBG_MODEL=isnet-general-use`.
- `silueta` режет хуже, чем `isnet-general-use`: на сложных товарах бывают огрехи.
- Фото уходят в Gemini. На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов.
- Диск на Render временный: дневные лимиты (`usage.db`) сбрасываются при перезапуске.
- Стиль «AI-сцена» платный (fal.ai) и скрыт, пока нет `FAL_KEY`.
